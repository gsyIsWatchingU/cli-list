# 功能清单

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 独立桌面应用 | 已完成 | 以安装包交付，双击 `CLIList.exe` 或桌面快捷方式即可打开 |
| AI 增量修改命令 | 已完成 | 自然语言生成增量指令，本地预览、白名单校验、应用与恢复 |
| JSON 命令配置 | 已完成 | 共享默认值与个人覆盖分层保存 |
| CLI 搜索 | 已完成 | 支持按名称、描述和标签搜索 |
| CLI 标签 | 已完成 | 配置多标签并按标签筛选 |
| 使用频率统计 | 已完成 | 本地记录执行次数与最近使用时间，支持排序 |
| 当前目录传递 | 已完成 | 使用 `{context}` 注入目录 |
| 目录浏览 | 已完成 | 支持进入目录、返回上一级和刷新 |
| 文件预览 | 已完成 | 支持文本、代码和常见图片 |
| PowerShell 启动 | 已完成 | 可在当前或选定目录启动 |
| 桌面快捷方式 | 已完成 | 安装脚本自动创建 |
| 终端命令 | 已完成 | 提供 `cli-list` 命令入口 |
| 全局快捷键 | 已完成 | 使用 `Ctrl + Alt + Space` 显示或隐藏命令面板，并确保窗口前置 |
| 可选右键菜单入口 | 已完成 | 作为独立应用的辅助入口，支持桌面、目录、文件和磁盘上下文 |
| 托盘驻留 | 已完成 | 开机启动、托盘退出并保持快捷键可用 |
| 单实例与目录转交 | 已完成 | 重复启动通过 Named Pipe 将当前目录交给驻留进程 |
| 极简像素界面 | 已完成 | 统一主面板与目录窗口视觉 |
| 自动构建检查 | 已完成 | GitHub Actions 在 Windows 上构建验证 |
| 拉取后自动更新 | 已完成 | 首次安装配置 Git Hook，后续 `git pull` 自动构建、验证、同步并重启 |
| 共享与本机配置 | 已完成 | `commands.json` 多端同步，`commands.local.json` 保存本机覆盖 |
| 下载即装 | 已完成 | Release zip 解压后首次运行引导安装，免管理员写入 HKCU 右键菜单 |
| 托盘卸载 | 已完成 | 托盘菜单一键卸载（移除菜单/快捷方式/安装目录） |
| 版本号 | 已完成 | 程序集版本 0.3.0，托盘与主窗口展示 |
| Release 自动化 | 已完成 | tag 触发打包 zip、SHA-256 校验文件、变更说明与 GitHub Release |
| 自动检查与一键更新 | 已完成 | 启动后静默检查；仅有新版时显示入口；安全切换、回滚与源码快进同步 |
