# 功能清单

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 右键菜单入口 | 已完成 | 支持桌面、目录、文件和磁盘上下文 |
| JSON 命令配置 | 已完成 | 修改配置即可增删命令 |
| 当前目录传递 | 已完成 | 使用 `{context}` 注入目录 |
| 目录浏览 | 已完成 | 支持进入目录、返回上一级和刷新 |
| 文件预览 | 已完成 | 支持文本、代码和常见图片 |
| PowerShell 启动 | 已完成 | 可在当前或选定目录启动 |
| 桌面快捷方式 | 已完成 | 安装脚本自动创建 |
| 终端命令 | 已完成 | 提供 `cli-list` 命令入口 |
| 极简像素界面 | 已完成 | 统一主面板与目录窗口视觉 |
| 自动构建检查 | 已完成 | GitHub Actions 在 Windows 上构建验证 |
| 图形化配置编辑器 | 待开始 | 后续替代手动编辑 JSON |
| 自动更新 | 暂缓 | 等待稳定发布流程 |
